# Desktop onboarding mockups

The visual source of truth for the desktop app's own pages, approved by the maintainer on
2026-11-20 (core spec `docs/superpowers/specs/2026-11-07-desktop-client-design.md`, header and
§6.1 to §6.10, §7.4). Open `canvas.json` for the board titles and the "rules" and "theme" notes;
each `*.dc.html` is one 480×600 small-window page or one 1280×800 main-window state. They use
JetBrains Mono and Noto Sans SC as stand-ins for the product's Sarasa Mono SC. Where a mockup and
the spec differ, the mockup wins for layout and copy, the spec for behaviour.

They are reference files, not app code: nothing imports them and they are not linted.
